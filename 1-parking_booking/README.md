# Система бронирования парковочных мест (ParkingBooking)

## Назначение
Веб-приложение для автоматизации учёта и бронирования парковочных мест, расчёта стоимости стоянки и формирования чеков для клиентов.

## Целевая аудитория
- Владельцы автомобилей, ищущие парковочное место.
- Администраторы парковочных комплексов.
- Управляющие компании ТЦ и БЦ.

## Предметная область
Управление парковочным пространством, бронирование мест на определённый период, учёт транспортных средств и клиентов, формирование финансовой отчётности.

## Основные сущности
- Пользователь (клиент)
- Автомобиль
- Парковочное место
- Период бронирования

## Основные функции
- Регистрация и аутентификация пользователей.
- Просмотр и поиск свободных парковочных мест.
- Бронирование места на указанный период.
- Расчёт итоговой стоимости стоянки.
- Управление статусами бронирования (активно, завершено, отменено).
- Формирование чеков и отчётов.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL/SQLite);
- реализация пользователей и ролевой модели;
- разработка REST API через Django REST Framework;
- контейнеризация приложения (Docker);
- настройка CI/CD.
