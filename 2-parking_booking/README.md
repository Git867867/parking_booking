# Система бронирования парковочных мест

Консольное приложение для учёта парковочных мест и бронирования
на период.

## Возможности

- просмотр и сортировка парковочных мест;
- проверка доступности места на выбранный период;
- создание бронирования с данными клиента и автомобиля;
- отмена бронирования;
- статистика по бронированиям;
- хранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска и меню;
- `spots.py` — функции работы с парковочными местами;
- `bookings.py` — функции работы с бронированиями;
- `storage.py` — загрузка и сохранение JSON-данных;
- `utils.py` — безопасный ввод пользователя;
- `data/` — файлы данных;
- `tests/` — автоматические тесты.
