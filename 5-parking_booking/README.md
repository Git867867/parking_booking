# Система бронирования парковочных мест

## Назначение

Система бронирования парковочных мест — приложение для учёта парковочных мест,
клиентов и бронирований.

Консольная версия приложения, разработанная в ПР3, дополнена веб-интерфейсом
на Django в ПР5.

Приложение позволяет:

* просматривать список парковочных мест в браузере;
* просматривать информацию о конкретном парковочном месте;
* просматривать список бронирований в браузере;
* просматривать информацию о конкретном бронировании;
* проверять доступность парковочного места на текущую дату;
* создавать бронирования в консольной версии;
* отменять бронирования в консольной версии;
* добавлять пользователей в консольной версии;
* хранить данные между запусками приложения в JSON-файлах.

## Используемые технологии

* Python 3;
* Django 5.2 — веб-фреймворк;
* HTML — разметка веб-страниц;
* CSS и Bootstrap 5.3 — оформление страниц;
* pytest — автоматизированные тесты;
* flake8 — проверка качества кода.

## Предметная область

Основными объектами предметной области являются:

* парковочное место;
* пользователь;
* бронирование.

Пользователь может бронировать парковочное место на определённый период.

Одно парковочное место не может иметь два активных бронирования
на пересекающиеся даты.

Отменённое бронирование не блокирует парковочное место
и позволяет создать новое бронирование.

## Основные сущности

### Spot — парковочное место

Объект `Spot` представляет парковочное место, доступное для бронирования.

Основные атрибуты:

* `id` — уникальный идентификатор места;
* `number` — номер места;
* `covered` — признак крытого места;
* `daily_rate` — цена за сутки.

### User — пользователь

Объект `User` представляет клиента системы.

Основные атрибуты:

* `id` — уникальный идентификатор пользователя;
* `name` — имя пользователя;
* `phone` — телефон пользователя.

### Booking — бронирование

Объект `Booking` связывает парковочное место и пользователя.

Основные атрибуты:

* `id` — уникальный идентификатор бронирования;
* `spot` — объект `Spot`;
* `user` — объект `User`;
* `start` — дата начала бронирования;
* `end` — дата окончания бронирования;
* `is_cancelled` — признак отмены бронирования.

## Страницы веб-интерфейса

* `/` — главная страница: описание приложения и навигация;
* `/spots/` — список парковочных мест;
* `/spots/<int:spot_id>/` — страница конкретного парковочного места;
* `/bookings/` — список бронирований;
* `/bookings/<int:booking_id>/` — страница конкретного бронирования.

Если парковочное место или бронирование с указанным идентификатором
не найдено, возвращается страница с кодом состояния 404.

## Основные операции

### Используется в веб-интерфейсе ПР5

* просмотр списка парковочных мест;
* просмотр информации о парковочном месте;
* просмотр списка бронирований;
* просмотр информации о бронировании;
* проверка доступности парковочного места на текущую дату.

### Сохранено в консольной версии ПР3

* добавление пользователя;
* создание бронирования;
* отмена бронирования;
* проверка доступности места на выбранный период;
* просмотр статистики;
* сортировка парковочных мест по цене.

### Отложено до следующих работ

В веб-интерфейсе операции создания и изменения данных появятся после
изучения Django Forms, POST-запросов и следующих этапов курса.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

* `data/spots.json`;
* `data/users.json`;
* `data/bookings.json`.

При загрузке данные из JSON преобразуются в объекты `Spot`, `User`
и `Booking`.

При сохранении объекты преобразуются в данные JSON.

Для связи бронирования с местом и пользователем в `bookings.json`
используются идентификаторы `spot_id` и `user_id`.
