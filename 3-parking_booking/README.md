# Система бронирования парковочных мест

Консольное приложение для учёта парковочных мест и бронирования
на период.

## Возможности

- просмотр и сортировка парковочных мест;
- управление пользователями;
- проверка доступности места на период;
- создание и отмена бронирований;
- статистика по бронированиям;
- хранение данных в JSON-файлах.

## Основные классы

### Spot — парковочное место

- **Атрибуты:** `id`, `number`, `covered`, `daily_rate`;
- **Методы:** `__init__()`, `__str__()`.

### User — пользователь системы

- **Атрибуты:** `id`, `name`, `phone`;
- **Методы:** `__init__()`, `__str__()`, `from_data()`.

### Booking — бронирование места

- **Атрибуты:** `id`, `spot`, `user`, `start`, `end`, `is_cancelled`;
- **Методы:** `__init__()`, `cancel()`, `days()`, `total_price()`, `__str__()`.

## Взаимодействие объектов

Объект `Booking` связывает объект `Spot` и объект `User`:

    booking.spot.number
    booking.user.name

При отмене бронирование не удаляется из коллекции — изменяется
его состояние `is_cancelled`. Отменённое бронирование не блокирует место.

## Структура проекта

- `main.py` — точка запуска и меню;
- `models/spots.py` — класс `Spot`;
- `models/users.py` — класс `User`;
- `models/bookings.py` — класс `Booking`;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод;
- `data/` — файлы данных;
- `tests/` — тесты pytest.
