# Система бронирования парковочных мест

Консольное приложение для учёта парковочных мест и управления бронированиями на основе объектно-ориентированного подхода.

## Возможности
- просмотр и сортировка парковочных мест;
- просмотр и добавление пользователей;
- проверка доступности места на выбранный период;
- создание бронирования с привязкой к клиенту;
- отмена бронирования;
- статистика по активным бронированиям и выручке;
- хранение данных в JSON-файлах с восстановлением объектных связей.

## Предметная область
Основными сущностями проекта являются:
- **Парковочное место (Spot)** — объект, доступный для бронирования.
- **Пользователь (User)** — клиент, который создает бронирования.
- **Бронирование (Booking)** — связь места и пользователя на определенный период времени.

Одно место не может иметь два активных бронирования на пересекающиеся даты. Отменённое бронирование не блокирует место.

## Основные классы

### `Spot` (Парковочное место)
Представляет парковочное место.
- **Атрибуты:** `id`, `number`, `covered`, `daily_rate`
- **Методы:** `__str__()` — строковое представление места.

### `User` (Пользователь)
Представляет клиента системы.
- **Атрибуты:** `id`, `name`, `phone`
- **Методы:** 
  - `__str__()` — строковое представление.
  - `@classmethod from_data()` — создание объекта из словаря (при загрузке из JSON).

### `Booking` (Бронирование)
Связывает объект `Spot` и объект `User` на определенный период.
- **Атрибуты:** `id`, `spot` (объект Spot), `user` (объект User), `start`, `end`, `is_cancelled`
- **Методы:**
  - `cancel()` — отмена бронирования (изменяет состояние, не удаляет объект).
  - `days()` — расчет количества дней.
  - `total_price()` — расчет итоговой стоимости.
  - `__str__()` — строковое представление с учетом статуса.

## Взаимодействие объектов
Объект `Booking` хранит прямые ссылки на объекты `Spot` и `User`. Это позволяет получать данные о месте и клиенте напрямую через атрибуты (например, `booking.spot.number` или `booking.user.name`). При сохранении в JSON объекты преобразуются в их идентификаторы (`spot_id`, `user_id`), а при загрузке — восстанавливаются путем поиска в коллекциях.
