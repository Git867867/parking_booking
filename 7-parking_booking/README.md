# 🚗 Система бронирования парковочных мест (Parking Booking)

Веб-приложение на базе фреймворка **Django** для управления парковочными местами и бронированиями. Проект позволяет просматривать доступные места, искать свободные парковки на выбранную дату, а также отслеживать статистику по бронированиям.

## 🌟 Основные возможности

*   **Парковочные места (`/spots/`)**:
    *   Просмотр полного списка мест.
    *   Фильтрация мест по типу (крытые/открытые).
    *   Поиск свободных мест на конкретную дату.
    *   Детальная информация о каждом месте с проверкой статуса (свободно/занято сегодня).
*   **Бронирования (`/bookings/`)**:
    *   Просмотр списка активных бронирований с привязкой к клиенту и месту.
    *   Детальная информация о бронировании (сроки, стоимость, статус).
*   **Статистика (`/bookings/statistics/`)**:
    *   Общее количество активных бронирований.
    *   Средняя и максимальная стоимость парковочного места.
    *   Рейтинг популярных мест (с количеством бронирований).
*   **Главная страница (`/`)**: Удобная навигация по разделам системы.

## 🛠️ Технологический стек

*   **Backend**: Python 3, Django 5.1
*   **База данных**: SQLite (используется кастомная БД `data/parking.sqlite` и стандартная `db.sqlite3` для админки)
*   **Frontend**: HTML5, CSS3, Bootstrap 5.3 (через CDN), Vanilla JS
*   **Тестирование**: Pytest, pytest-django
*   **Линтинг**: Flake8

## 📂 Структура проекта

*   `homepage/` — главная страница и обработчик 404 ошибки.
*   `spots/` — приложение для работы с парковочными местами (списки, фильтры, поиск).
*   `bookings/` — приложение для работы с бронированиями (списки, детали, статистика).
*   `models/` — бизнес-логика (классы `Spot`, `User`, `Booking` и функции для работы с ними).
*   `db/` — модуль подключения к БД и скрипт импорта `import_json.py`.
*   `data/` — JSON-файлы с начальными данными и файл базы данных SQLite.
*   `sql/` — SQL-скрипты (`schema.sql` для создания таблиц и `queries.sql` с примерами запросов).
*   `tests/` — юнит-тесты для моделей и логики бронирования.
